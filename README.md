# Kashish Milani portfolio (v4)

Open: double-click `index.html` (needs internet for the Host Grotesk font and the GSAP/Lenis libraries from CDN).

Style: rebuilt in the look of Nayab's saved reference (an "Elena Voss" template by Hyperiux). The code, images and copy are all new; content is Kashish's, unchanged.
- One font (Host Grotesk), orange to red gradient sections alternating with near-black.
- Hero: full-bleed red portrait card that pulls back into a wall of her decks and stills, then sinks.
- Entry 01 rises over it through a growing curve; contents as ruled rows with line icons.
- The Archive: the section holds while each scroll step wipes the next deck into a big viewer; the chapter list tracks progress.
- Work in Motion: big 385K+ counter, then a pinned sideways row of reel cards; the card in focus lights up.
- Frame by Frame: ruled list, each still opens like a shutter.
- Brand names blur in and out around "Nothing here exists without intent."
- Script Craft: pick a script (tabs), read the card, open the full script (+).
- Contact: glass card over a warm glow.
Phones: same hero, archive as a stacked list, reels as a swipe row. Reduced motion or no JS: every section is a normal readable block.

Backups: v3 in `../site-v3-backup/`, v2 in `../site-v2-backup/`.
